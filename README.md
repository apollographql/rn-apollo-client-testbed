## Preparations

- clone https://github.com/apollographql/rn-apollo-client-testbed
- `npm install`

### Quick Start (Android and iOS)

Install Expo Go ([Download Expo Go here](https://expo.dev/go)) on your emulator or phone.
Then run `npm run android` or `npm run ios` to start the app in Expo Go.

## Debugging

### Using the Chrome debugger

- Toggle the JS Debugger by pressing "j" in the Expo command line
- A Chrome window with DevTools for the running app should open

### Using the Apollo GraphQL VSCode extension to inspect Apollo Client cache

Please see [Apollo Client Devtools in VS Code](https://www.apollographql.com/docs/react/development-testing/developer-tooling#apollo-client-devtools-in-vs-code) for more details.
